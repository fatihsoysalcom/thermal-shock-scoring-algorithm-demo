# Thermal Shock Scoring Algorithm Demo

This example demonstrates a simplified thermal shock scoring algorithm. It calculates a 'thermal shock index' based on temperature change rates and key material properties (Young's Modulus, thermal expansion coefficient, thermal conductivity). The algorithm identifies the most severe thermal shock event within a given temperature profile and assigns a risk level, illustrating how different materials react to the same thermal conditions.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
